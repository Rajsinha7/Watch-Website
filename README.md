# Watch-Website
A sleek and visually appealing Watch Website built using HTML, CSS, and JavaScript.
The project showcases modern timepiece designs and functionality with a clean UI and smooth user experience.

--> Features
- Elegant watch design showcase
- Clean and modern user interface
- Fully responsive layout (mobile, tablet, desktop)
- Interactive elements using JavaScript
- Smooth styling and animations

--> Tech Stack
-HTML5 – Structure of the website
-CSS3 – Styling, layout, and responsiveness
-JavaScript – Interactivity and functionality

_--> Project Structure

├── index.html

--> How to Run the Project

-Clone the repository:
-git clone https://github.com/your-username/watch-website.git
-Open the project folder:
-cd watch-website
-Open index.html in any web browser.
